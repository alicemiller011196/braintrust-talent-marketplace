# Braintrust Talent Marketplace MVP

A polished MVP for a talent marketplace and client collaboration platform inspired by Braintrust.

## Features

- Landing page for a talent hiring marketplace
- Talent discovery cards with expertise, rate, and availability
- Project listings and detail pages
- Client dashboard with pipeline and activity
- Login and signup experience
- Responsive dark UI styled for modern hiring platforms

## Tech stack

- Next.js 14
- TypeScript
- Tailwind CSS
- React

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the app locally:
   ```bash
   npm run dev
   ```

3. Open http://localhost:3000

## Project structure

- `app/` — route pages and layout
- `components/` — UI building blocks
- `data/` — mock content used for the MVP
- `lib/` — shared utilities

## Notes

This is an MVP frontend built with realistic mock data. It is structured to be extended with authentication, database models, real project submissions, messaging, and payment integrations.
